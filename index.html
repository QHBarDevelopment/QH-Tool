How to Count

▸
  1. Check that the Bar Batches bottle configuration is correct, then check that the General Configuration (container) values are correct.
  2. Take the readings using the scale: weigh the largest possible number of bottles together and note the total weight in Kg.
  3. Keep track of how many bottles were placed on the scale for that reading, and enter both values into the table.
  4. If you weigh more than one batch of bottles, add another group so every bottle gets accounted for.
  5. Calculate and export the generated table to add to your records afterward.

Marketman Bar Batch List

  1. Create a new inventory count in Marketman. Select only the Batches group.
  2. Tap the sheet-shaped icon at the top and select "Export Count Sheet".
  3. Filter the Excel table exactly as shown in the example below — the Type and Qty columns must not be edited.
  4. Leave the table exactly like the example image: keep in mind that Bar Batches are counted in L, so this table must not include the Big Cambros.
  1. Save and export the document in Excel format.

Note: this document only updates names — it automatically renames the items in both Bar Batches and Batches (Batch Prep) at the same time, without touching any configuration values already entered. It's also the same file exported at the end of a count, so it can be re-imported into Marketman to make adding it to inventory easier.
